# Lugus plugin protocol v1

JSON-RPC 2.0, one UTF-8 JSON object per line on stdout/stdin. No batches or notifications. Integer request IDs echoed in responses. stderr is diagnostics only. Major version 1. One request at a time. All date ranges inclusive.

Manifest: `{"id":"sec-edgar","version":"0.1.0","protocol_version":1,"command":"python3","args":["main.py"]}`. Working directory is the manifest directory; relative commands containing a path are resolved against it. Configuration is sent only via initialize, never persisted.

`initialize` params: `{"protocol_version":1,"config":{"user_agent":"Lugus Name contact@example.com"}}`. Result: `{"protocol_version":1,"plugin_id":"sec-edgar","plugin_version":"0.1.0","capabilities":{"filings":1,"fundamentals":1}}`.

`filings.list` and `fundamentals.facts` params are Query:
```json
{"company":{"namespace":"sec:cik","value":"0000320193"},"filed_from":"2023-01-01","filed_to":"2024-12-31","forms":[],"cursor":null,"page_size":100}
```
Page result: `{"items":[],"next_cursor":null}`. Maximum page_size 1000. Cursors are opaque, tied to method and query, and valid only in this initialized process. Source failures must not become empty pages. Forms filter applies to both capabilities.

Fact:
```json
{"company":{"namespace":"sec:cik","value":"0000320193"},"namespace":"us-gaap","concept":"Assets","label":"Assets","value":"352583000000","unit":"USD","period":{"kind":"instant","date":"2023-09-30"},"filing_id":"0000320193-23-000106","form":"10-K","filed":"2023-11-03","fiscal_year":2023,"fiscal_period":"FY","source_url":"https://data.sec.gov/api/xbrl/companyfacts/CIK0000320193.json","retrieved_at":"2026-09-09T12:00:00Z"}
```
Duration period: `{"kind":"duration","start":"2022-09-25","end":"2023-09-30"}`. Value is a plain exact decimal string, not a JSON number, exponent, NaN or Infinity. Optional fields label/fiscal_year/fiscal_period may be null. Mapping and provider identity are attached by host, never trusted from plugin.

Filing:
```json
{"company":{"namespace":"sec:cik","value":"0000320193"},"filing_id":"0000320193-23-000106","form":"10-K","filed":"2023-11-03","report_date":"2023-09-30","accepted_at":null,"primary_document":"aapl-20230930.htm","source_url":"https://www.sec.gov/Archives/edgar/data/320193/000032019323000106/aapl-20230930.htm","retrieved_at":"2026-09-09T12:00:00Z"}
```
report_date, accepted_at, primary_document may be null. accepted_at is UTC only when source supplies an unambiguous instant.

`filings.document` params: `{"source_url":"<URL from filing>","max_bytes":10485760}`. Result: `{"source_url":"...","media_type":"text/html","content_base64":"...","retrieved_at":"..."}`. Reject oversized data rather than truncate it. SEC provider only accepts HTTPS SEC archive URLs and validates redirect destinations.

Error response: `{"jsonrpc":"2.0","id":1,"error":{"code":-32000,"message":"description","data":{"kind":"rate_limited","retry_after_seconds":2}}}`. Kinds: invalid_request, unsupported, configuration, rate_limited, unavailable, not_found, malformed_data, protocol, timeout. Retry delay optional. Standard JSON-RPC parse/request/method errors use -32700/-32600/-32601/-32602. Bounded retry inside provider applies only to idempotent transient network failures; host does not retry invisibly.

Host default timeout 60 seconds, maximum response line 32 MiB, maximum document 10 MiB. Plugin uses bounded network timeouts and validates input before requests. Plugin protocol stdout must be flushed after every response.

Optional market-data methods are specified in [market-data capability v1](market-data-v1.md). Plugins advertise only the capabilities they implement; the protocol major version remains 1.
